📝 BlogSpot – Blogging Website
📌 Project Overview

BlogSpot is a dynamic blogging web application developed to allow users to create, manage, and explore blog content through a clean and user-friendly interface. The project focuses on content publishing, user interaction, and responsive web design.

The website enables users to write blogs, manage posts, and organize content efficiently.

🎯 Features
User-friendly blogging platform
Create, edit, and delete blog posts
Responsive website design
Dynamic content rendering
Category-wise blog organization
Clean and modern UI
⚙️ Technologies Used
HTML
CSS
JavaScript
Python
Django
SQLite
🚀 Workflow
User creates or views blog posts
Backend processes requests using Django
Data stored and managed in database
Dynamic content displayed on webpages
